# C - Hash Tables

## Description
This project focuses on implementing Hash Tables in C, covering data structures, collision handling using chaining, djb2 algorithm, and basic Hash Table operations such as creating, setting, retrieving, printing, and freeing memory.

## Tasks & Files
| File | Description |
| --- | --- |
| `0-hash_table_create.c` | Function that creates a hash table |
| `hash_tables.h` | Header file containing structures and function prototypes |

## Requirements
- Editors: `vi`, `vim`, `emacs`
- OS: Ubuntu 20.04 LTS
- Compiler: `gcc` using flags `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Style: Betty style guidelines
